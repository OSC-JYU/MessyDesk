Service: md-lingua

MD-Lingua Service

The MD-Lingua service uses Lingua, a deterministic, statistical language detector, to figure out which language a text is written in. Unlike many AI tools, the same input always gives the same result, and detection works offline with no external API calls.

Available Crunchers

detect_language — Detect language

Detects the language of a text file and marks the language(s) found, using ISO codes (e.g. en, fr, de).

  • By default (Allow multiple languages unchecked), the single most confident language for the whole document is reported.
  • If Allow multiple languages is checked, the text is scanned for mixed-language sections and each distinct language segment found is reported separately, with its position in the text. This works best on longer segments per language — very short, tightly mixed phrases are less reliable.
  • Create tags is checked by default: it also creates a regular tag per detected language, so files can be filtered by language in Sets. Uncheck it if you only want the detailed per-segment browsing without adding tags.

Detailed per-segment results always show up in the Tags view like other span-based crunchers (e.g. MD-GLiNER2's "Find named entities"), regardless of the Create tags setting.
