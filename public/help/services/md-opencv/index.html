Service: md-opencv

MD-OpenCV Service

The MD-OpenCV service utilizes Python-based OpenCV scripts to manipulate, transform, and extract visual data from images using Regions of Interest (ROIs).

This service primarily operates on roi.json metadata layers linked to your image nodes. It allows you to modify specific areas of an image or extract them for separate downstream pipelines.

Available Crunchers

extract (Extract ROI)

Cuts out the designated Regions of Interest from a single image and saves them as separate, standalone image nodes.

  • Graph Behavior: One-to-Many (outputs a new set containing each extracted ROI fragment).

isolate (Isolate ROI)

Isolates the targeted ROIs by keeping them perfectly intact while completely masking or blacking out the rest of the image canvas. This is highly useful when you want to eliminate background noise or irrelevant page artifacts before running machine learning models.

  • Graph Behavior: One-to-Many
  • Parameters:
    • labels (boolean, default: false): When checked, prints the ROI metadata names directly onto the isolated image segments.

fill (Fill ROI)

Overlays a solid color block directly on top of the designated image ROIs. You can use this to permanently censor or redact sensitive visual elements, face detections, or text blocks.

  • Graph Behavior: One-to-Many
  • Parameters:
    • color (string, default: "ffffff"): Accepts a hex code defining the fill color (defaults to solid white).

border (Border ROI)

Draws sharp, visible bounding boxes around your mapped image ROIs. This is ideal for validating AI-assisted detections or creating clear figures for your research publications.

  • Graph Behavior: One-to-One (modifies a copy of the single image canvas).
  • Parameters:
    • labels (boolean, default: false): Draws text labels above the borders to display individual ROI metadata notes.

blur (Blur ROI)

Applies a blurring filter strictly within the boundaries of the selected ROIs, leaving the rest of the image in sharp focus. This is a common alternative to fill for anonymizing personal identifiers or faces while maintaining page context.

  • Graph Behavior: One-to-One
  • Parameters:
    • labels (boolean, default: false): Overlays identifying text labels over the blurred regions.

binary (Binary ROI)

Applies a sharp binary threshold (converting the area to high-contrast pure black and white pixels) strictly inside the designated ROIs. This can dramatically improve accuracy before sending low-quality or aged document snippets into text recognition (OCR) tools.

  • Graph Behavior: One-to-One

binary_invert (Binary Invert ROI)

Applies an inverted binary threshold exclusively inside the ROIs, flipping the black and white pixel values.

  • Graph Behavior: One-to-One
