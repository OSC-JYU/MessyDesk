Service: md-minisbd

MD-MiniSBD Service

The MD-MiniSBD service uses MiniSBD (an ONNX port of Stanza's tokenizer models) to split plain text into sentences across 80+ languages.

Available Crunchers

find_sentence_boundaries — Find sentence boundaries

Detects sentence boundaries in the input text and rewrites it accordingly.

  • Language — pick the language of your text. Detection quality depends on having the right language model.
  • Output format:
    • Continuous text (default) — each paragraph is kept as a single flowing line of text, with sentence boundaries normalized internally.
    • Sentence per line — every detected sentence is written on its own line, one sentence per line.
  • Both output formats preserve blank lines between paragraphs, so chapter/section breaks in the original document are not lost.
