# FAQ

#### What core services are available?

MessyDesk relies on several built-in, foundational services to handle standard file workflows. These are always available in your workspace:

* **Thumbnailer Service (*Imaginary*):** Automatically generates visual preview cards for your files in the graph.
* **PDF extract Service (*Poppler*):** Extracts text and embedded images from documents, and renders page previews.
* **ZIP Service:** Handles the background archiving, extraction, and downloading of sets.
* **PDF Splitter Service (*PyPDF*):** Drives a cruncher that breaks multi-page documents into individual page nodes.
* **Search Service (*Solr*):** Powers the project-scoped search indexing and query functionalities.
* **Base Text Utilities (*Python*):** Handles foundational string operations like splitting or joining text files.
* **Base Image Utilities (*Imaginary*):** Handles foundational image operations like rotate, flip and scale.
* **Simple OCR (*Tesseract*):** Simple and fast optical character recognition cruncher.

*Note: Access to advanced processing engines or specialized machine learning crunchers depends on your specific user permissions and the services enabled for your workspace.*

#### Can I run MessyDesk locally on my own computer?

Yes, but with some caveats. MessyDesk is architected from the ground up as a multi-user web application. Because it relies on a distributed cluster of microservices (like Solr and Poppler) to handle heavy data processing, setting it up on a local machine is more complex than installing a typical desktop application.

* **Operating System Support:** The ideal and primary deployment environment for MessyDesk is **Linux**. 
* **Other Platforms:** While there are no hard architectural blocks preventing it from running on Windows or macOS (for example, via containerization tools like Docker), these environments are not currently tested or officially supported. Setting it up on non-Linux systems may require manual troubleshooting.
