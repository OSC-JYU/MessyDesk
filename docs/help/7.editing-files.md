# Correcting outputs

Let's take an example: You detected text from images and the result is almost right. Then it is sensible to fix that error.
But if you modify the result of optical character recognition, then we do not know anymore what was the machine product and what was corrected.

Solution: Make new version

MessyDesk do not allow users to edit files themselves. Instead you can create a corrected version. This way it is always clear who contributed and what.

Corrected version is then always used when you process file. You can revert back to original version and then your corrected version is permanently lost.

Note that you cannot create corrected version of file if file itself is already processed somehow. This prevents situation where your workflow is not up to date i.e. the input file is different that what the output file is based on.
