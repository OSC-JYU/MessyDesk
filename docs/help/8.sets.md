# Working with Sets

You can think of **Sets** as folders, with one major distinction: **Sets cannot be nested.** There are no subfolders within a set; they are strictly flat collections of files.

Sets are designed to enable the batch processing of files. Just as you would connect a cruncher to an individual file node, you can connect that same cruncher to an entire set to process all its files simultaneously.

![An input set of images passing through an 'Image to text' OCR cruncher to output a set of text files](sets.jpg)

## Batch Processing

When you pass a set through a cruncher, MessyDesk processes every item inside that collection using the same parameters. 

As shown in the example above, passing a set of two images through an **Image to text** cruncher automatically generates a matching output set containing the extracted text files (`.txt`) for each corresponding image.

Note that crunchers can behave three distinct ways with sets.

* **One-to-One:** Each input file produces exactly one corresponding output file. For example, passing a set of images through an **Image to text** (OCR) cruncher creates a matching set of individual text files.
* **One-to-Many:** A single input file is expanded into multiple output files, automatically forming a new set. For example, applying a **PDF Split** cruncher to a single multi-page PDF node expands it into a set containing its individual pages.
* **Many-to-One:** An entire set of input files is consolidated into a single output node. For example, applying a **JSON to CSV** cruncher to a set of separate JSON data files aggregates them into a single, unified CSV spreadsheet.

## Creating Sets Efficiently

Manually adding files to a set one by one is tedious. The quickest and most efficient way to build a set is to leverage the ZIP workflow:

1. Compress your working files into a `.zip` archive on your computer.
2. Import that ZIP file into MessyDesk.
3. Apply an **Unzip** cruncher to the archive node.

The cruncher will automatically extract the files and create a set, ready for batch crunching.

## Exporting sets

Once you are done processing your data, you can easily download your results. Simply select the desired set node in the interface graph and click **Download set** to export the entire collection back to your computer as a structured ZIP file.
