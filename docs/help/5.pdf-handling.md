# PDF Handling

MessyDesk treats PDF as a container of pages.

When you upload a PDF it is stored as it is: an **original PDF**. Nothing happens to it until you choose to split it. The only cruncher offered for an original PDF is **PyPDF → Split PDF to pages**, which makes **one-page PDF files** in a new set. Other PDF crunchers, such as **Poppler**, work on those pages.

> **WARNING:** By default the original PDF is REMOVED from disk after splitting, to save space. The node stays on the desk, marked as removed. You can turn the removal off before you run the split.

There are couple of reasons for working with pages. First reason is technical. PDF files can be very large, especially when it includes digitised content. Processing large files requires lot of memory and may lead corrupted results in some cases. Splitting file to smaller units resolves this problem.

Second reason is semantic. In many fields that work with digitized information, a PDF file is often used as a package that bundles multiple documents together. The reason them being in same file might be that they located in paper folder. Because of this, it makes more sense to treat individual pages as the basic processing unit rather than the entire file, while still preserving the connection to the original document.

When working with PDF files that contain hundreds of pages, splitting the file into separate single-page PDFs allows processing and classification to happen at the page level.

**NOTE** Individual pages are still connected to the original file in the graph, and each page keeps its page number in its name (`page_008.pdf`).

## Splitting a PDF

1. Select the PDF and open the crunchers. Choose **PyPDF → Split PDF to pages**.
2. Choose the options:
   * **Pages:** which pages to split. Leave it empty to split all pages. Otherwise give a range, for example `1-5,8,10-` (pages 1 to 5, page 8, and page 10 to the end). `-5` means the first five pages.
   * **Delete the original PDF after splitting:** on by default. Turn it off to keep the PDF file.
3. Run it. The pages appear in a new set called "PDF pages". You can also select a set of PDFs to split all of them at once.

> **WARNING:** If you split only a range of pages and delete the original, the other pages are lost for good. Turn the removal off if you may need them later. MessyDesk shows a warning when you do this.

A PDF that was extracted from a ZIP file is an original PDF too, and it is split in the same way.

## Working with the pages

**Poppler** (text, page images, embedded images and PDF info) can only be applied to the pages, not to an original PDF. Select a page, or the set of pages.

When you run Poppler on a set of pages you can give **Pages**, a range like above. Only those pages are processed. The numbers are the page numbers of the original PDF, so `5-8` means the pages `page_005` to `page_008`, wherever they are in the set. If the set holds pages of several PDFs, the range is applied to each of them. Leave it empty to process the whole set.

# What is inside a PDF file?

A PDF file can contain many different kinds of content, ranging from images and forms to interactive elements and even games.

A PDF may contain:
- only text
- only images
- both text and images
- images with invisible OCR text behind them
- hidden images layered beneath visible content

It can even contain images that appear tiny on screen but are actually hundreds of megabytes in size.

In other words, what you see is not necessarily what a machine sees.

This is especially important when processing PDF files with machine learning models. You need to understand what the AI actually "sees," because it may differ significantly from what is visually shown to the user.

---

## How to extract content from PDF files

There are three main ways to extract content from PDF files.

### 1. Extract text objects from the PDF

If you create a document in a text editor and save it as a PDF, the text remains embedded inside the file and can be extracted directly.

The same applies to scanned documents that contain OCR text. In these cases, the OCR text can usually be extracted even if it is invisible to the user and only the scanned image is shown visually.

In MessyDesk, this can be done using the **Poppler** cruncher with the task **"Extract text"**.

---

### 2. Extract image objects from the PDF

Extracting images from a PDF retrieves all embedded image objects, including both visible and hidden images.

The extracted images preserve their original resolution and quality from when they were added to the PDF.

---

### 3. Render the PDF page as an image

Rendering converts a PDF page into an image, essentially creating a screenshot of the page.

This method captures exactly what is visually shown to the user.

It is also the safest method when you want to ensure that hidden layers, invisible OCR text, or concealed content are not included in the extracted result.
