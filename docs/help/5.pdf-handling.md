# PDF Handling

MessyDesk treats PDF as a container of pages.

> **WARNING:** When PDF is imported to MessyDesk, it is automatically splitted to one-page PDF files and original file is REMOVED.

There are couple of reasons for this. First reason is technical. PDF files can be very large, especially when it includes digitised content. Processing large files requires lot of memory and may lead corrupted results in some cases. Splitting file to smaller units resolves this problem.

Second reason is semantic. In many fields that work with digitized information, a PDF file is often used as a package that bundles multiple documents together. The reason them being in same file might be that they located in paper folder. Because of this, it makes more sense to treat individual pages as the basic processing unit rather than the entire file, while still preserving the connection to the original document.

MessyDesk does exactly this. When working with PDF files that contain hundreds of pages, splitting the file into separate single-page PDFs allows processing and classification to happen at the page level.


**NOTE** Individual pages are still connected to original file name.

# What is inside a PDF file?

A PDF file can contain many different kinds of content, ranging from images and forms to interactive elements and even games.

A PDF may contain:
- only text
- only images
- both text and images
- images with invisible OCR text behind them
- hidden images layered beneath visible content

It can even contain images that appear tiny on screen but are actually hundreds of megabytes in size.

In other words, what you see is not necessarily what a machine sees.

This is especially important when processing PDF files with machine learning models. You need to understand what the AI actually "sees," because it may differ significantly from what is visually shown to the user.

---

## How to extract content from PDF files

There are three main ways to extract content from PDF files.

### 1. Extract text objects from the PDF

If you create a document in a text editor and save it as a PDF, the text remains embedded inside the file and can be extracted directly.

The same applies to scanned documents that contain OCR text. In these cases, the OCR text can usually be extracted even if it is invisible to the user and only the scanned image is shown visually.

In MessyDesk, this can be done using the **Poppler** cruncher with the task **"Extract text"**.

---

### 2. Extract image objects from the PDF

Extracting images from a PDF retrieves all embedded image objects, including both visible and hidden images.

The extracted images preserve their original resolution and quality from when they were added to the PDF.

---

### 3. Render the PDF page as an image

Rendering converts a PDF page into an image, essentially creating a screenshot of the page.

This method captures exactly what is visually shown to the user.

It is also the safest method when you want to ensure that hidden layers, invisible OCR text, or concealed content are not included in the extracted result.
