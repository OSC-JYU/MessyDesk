# MessyDesk tools

>  "Research first. AI second."

The tool categories in MessyDesk reflects the different ways researchers work with image and text data. Since MessyDesk is designed for academic research, the categories also help separate fully manual work from deterministic methods, machine learning tools, and AI-based tools. This makes it easier to choose the right tool for the task and to understand how each result was produced.

## Tool categories


:::columns 4
### Preparation & annotation

**STAMP:green** Human / deterministic

Preprocessing tools help you understand your material. There is no AI here. Nothing is decided for you. 

You can tag documents, sort them into your own categories, or just read them. With images, you can manually mark and crop the parts that matter to you.

Preprocessing tools also include simple optical character recognition for clearly printed texts.

TOOLS:
- regions of interest (ROI)
- manual classification (tagging)
- cropping
- format conversion
- resolution conversion
- simple OCR 
- text search

tags: no-generative-AI, manual selection, manual classifying, local



---
### Linguistic & statistical analysis

**STAMP:green** Deterministic / statistical

Traditional natural language processing tools use fixed rules and repeatable methods. This means the same input gives the same result. That is different from many AI tools.

TOOLS:
- topic modelling
- part of speech (POS) analysis including base forms
- similarity searches
- frequency analysis

tags: no-generative-AI, local



---
### Task-specific machine learning

**STAMP:green** Trained models

Machine learning tools use trained models, but not large language models.

- HTR
- advanced OCR
- named entity regocnition (NER)
- personally identifiable information (PII) detection
- classification
- object detection
- machine translation
- semantic search/semantic topic modelling
- other trained DH models

tags: no-generative-AI, advanced OCR, advanced HTR, NER, local



---
### Generative AI

**STAMP:red** LLM / VLM

AI tools includes the use of large language and visual language model for different purposes.

- generic OCR/HTR
- LLM classification
- image description
- summarisation
- question answering
- metadata generation
- extraction

tags: AI, external, local, LLM, prompting




:::
