# Regions of Interest (ROIs)

As the name implies, a **Region of Interest (ROI)** is a specific segment of an image or text file that a researcher flags for further analysis or targeted processing.

## Image ROIs (Polygons)

Image ROIs allow you to draw shapes over specific areas of a visual node to isolate them. Instead of permanently cropping or altering your original file, MessyDesk treats these polygons as abstract layer markings. 

Because ROIs exist as independent metadata layers rather than destructive edits, they can be utilized in several distinct ways:
* **Targeted Processing:** You can instruct a cruncher to process *only* the data contained within a specific ROI (e.g., running OCR on a single column of an ancient manuscript page).
* **Metadata & Annotations:** You can attach unique labels, metadata tags, and descriptive research notes to individual ROIs without affecting the parent node.
* **Pipeline Routing:** An ROI can be extracted to create a new downstream data node while preserving the original image's context.

## AI-Assisted ROIs *(Planned Feature)*

When dealing with massive visual archives, manually drawing polygons becomes impossible. Future updates will introduce automated computer vision crunchers to do the heavy lifting:
* **Object & Face Detection:** For example, an object-detection pipeline can scan thousands of images to identify human faces, structural elements, or historical artifacts, automatically generating bounded ROIs for every match.
* **Batch Annotation:** These machine-generated ROIs can then be filtered, reviewed, and fed into subsequent analysis pipelines.

## Text ROIs *(Planned Feature)*

While image ROIs deal with geometric polygons, Text ROIs handle highlighted strings and sequences within textual documents. 

### Named Entity Recognition (NER)
Text ROIs will integrate natively with Named Entity Recognition workflows. When an NER cruncher processes a text, it automatically generates a collection of precision-mapped text ROIs. 

Each generated ROI retains:
* The exact character start and end points of the sequence.
* The extracted text snippet.
* The entity classification (e.g., *Person*, *Location*, *Organization*, or *Date*).
