# Visual Workflows with MessyDesk

If you are used to traditional desktop tools, a node-based interface might feel unfamiliar at first. However, when dealing with complex data processing a visual graph is the most reliable way to maintain control over your workflow.

![A MessyDesk project graph showing an image passing through Extract, Flip, Blur, and Rotate crunchers](nodes.jpg)

## Understanding the Graph

Under the hood, MessyDesk operates as a directed graph. 

* **Data Nodes:** Every file you import or create is represented as a visual card (node).
* **Crunchers:** Every action you take—whether it's cropping an image, rotating it, or running a search query—is a processing node connected by lines.

When you apply a cruncher to a file, the resulting output is automatically linked to its input file. As your project grows, this forms a clear, unbroken pipeline. Because every step is hardlinked, **you can always trace any output file back to the original source.**

> 💡 **Core Benefit:** You never lose context. You will always know exactly which version of a text or image you are looking at.

## Self-Documenting Pipelines

One of the greatest advantages of a node-based interface is that it documents itself. Instead of digging through automated logs or trying to decipher cryptic filenames in a folder, your entire methodology is laid out visually. 

* **Visual History:** You can see precisely what operations (e.g., extracting a region of interest, flipping, or blurring) were performed, and in what exact order.
* **In-Line Annotations:** You can write notes directly onto your cruncher and file nodes to document your thought process, hypotheses, or processing choices as you work.

> 💡 **Core Benefit:** Reproducibility is built-in. You—and your collaborators—never have to guess how a final dataset was generated.
