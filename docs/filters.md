# Filters

Filters allow user to make selections from sets.

## Image ROIs (polygons)

Image ROIs (Region Of Interest) are regions that mark interesting parts of the image. With these user can define what areas of images should be processed. 

Examples:
Simple crop where margins of the image are cropped out.
Table columns mark up.


Regions are JSON files and they get linked to Image files. This allows using them as a linking tool to point to certain part of the image.
